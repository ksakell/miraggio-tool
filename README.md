# Miraggio Offer & Confirmation Generator

Εργαλείο σε ένα μόνο αρχείο HTML (`miraggio_generator_mobile.html`) που δημιουργεί επιστολές **επιβεβαίωσης κράτησης / προσφοράς** για το **Miraggio Thermal Spa Resort**. Συμπληρώνεις τα στοιχεία της κράτησης σε μια φόρμα, βλέπεις αμέσως την επιστολή όπως θα τυπωθεί και την εξάγεις σε PDF (A4) από το παράθυρο εκτύπωσης του browser.

Δεν χρειάζεται server, build ή εγκατάσταση. Όλος ο κώδικας (HTML, CSS, JavaScript) βρίσκεται μέσα στο ίδιο αρχείο. Η σελίδα λειτουργεί και σε κινητό.

## Δυνατότητες

- **Κλείδωμα με κωδικό**: ο κωδικός ζητείται σε κάθε φόρτωση της σελίδας. Τίποτα δεν αποθηκεύεται ανάμεσα στις επισκέψεις.
- **Φόρμα κράτησης**:
  - Όνομα επισκέπτη και αριθμός επιβεβαίωσης
  - Τύπος διατροφής: Breakfast, Half Board, Half Board Plus ή Full Board
  - Ημερομηνίες άφιξης και αναχώρησης. Οι νύχτες υπολογίζονται αυτόματα και μπορείς να τις αλλάξεις με το χέρι.
  - Έως **5 γραμμές δωματίων**. Κάθε γραμμή έχει τύπο δωματίου, ποσότητα, άτομα, αρχική τιμή ανά νύχτα και ειδική τιμή ανά νύχτα.
- **Ζωντανή προεπισκόπηση της επιστολής**:
  - Ένα μπλοκ για κάθε διαφορετικό τύπο δωματίου, με περιγραφή, 4 φωτογραφίες και τη λίστα παροχών. Τα δωμάτια Club και οι σουίτες δείχνουν τις παροχές Miraggio Club, τα υπόλοιπα τις βασικές παροχές.
  - Στοιχεία επισκέπτη και κράτησης (check-in 15:00, check-out 11:00).
  - Οικονομική σύνοψη. Η αρχική τιμή εμφανίζεται διαγραμμένη και δίπλα φαίνεται η ειδική τιμή. Τα σύνολα υπολογίζονται ως `ποσότητα × νύχτες × τιμή`.
  - QR code για την εφαρμογή, σημείωση για τον φόρο διαμονής και τραπεζικά στοιχεία.
- **Εκτύπωση / PDF**:
  - Πριν ανοίξει το παράθυρο εκτύπωσης, το εργαλείο περιμένει έως 6 δευτερόλεπτα να φορτώσουν οι φωτογραφίες.
  - Το προτεινόμενο όνομα αρχείου είναι `Όνομα ｜ Αρ. Επιβεβαίωσης ｜ Miraggio Thermal Spa Confirmation`.
  - Όταν η κράτηση έχει έναν μόνο τύπο δωματίου, η διάταξη γίνεται πιο συμπαγής ώστε η επιστολή να χωράει σε δύο σελίδες.
- **Φωτογραφίες** από Google Drive. Αν μια φωτογραφία δεν φορτώσει, εμφανίζεται εικόνα placeholder.
- **Υποστήριξη iOS "Add to Home Screen"**: η σελίδα ανοίγει σε πλήρη οθόνη, σαν εφαρμογή, με δικό της εικονίδιο.

## Πώς τρέχει

### Τοπικά
1. Κατέβασε ή κάνε clone το repository.
2. Άνοιξε το `miraggio_generator_mobile.html` σε browser (διπλό κλικ ή σύρσιμο στο παράθυρο).
3. Χρειάζεται σύνδεση στο internet για να φορτώσουν οι φωτογραφίες.

Αν θέλεις τοπικό server, π.χ. για δοκιμές:

```bash
python3 -m http.server 8000
# μετά άνοιξε http://localhost:8000/miraggio_generator_mobile.html
```

### Online (GitHub Pages ή άλλο static hosting)
Ανέβασε το αρχείο σε οποιαδήποτε υπηρεσία static hosting, για παράδειγμα GitHub Pages (Settings → Pages). Μετά άνοιξε τη διεύθυνση από υπολογιστή ή κινητό.

### Στο iPhone σαν εφαρμογή
Άνοιξε τη σελίδα στο Safari και πάτα **Share → Add to Home Screen**.

## Χρήση

1. Γράψε τον κωδικό και πάτα **Unlock** ή Enter.
2. Συμπλήρωσε τα στοιχεία του επισκέπτη, τη διατροφή και τις ημερομηνίες.
3. Πρόσθεσε δωμάτια με το **+ Add Room** (έως 5) και συμπλήρωσε τύπο, ποσότητα, άτομα και τιμές.
4. Έλεγξε την επιστολή στην προεπισκόπηση κάτω από τη φόρμα.
5. Πάτα **Print / Export to PDF** και στο παράθυρο εκτύπωσης διάλεξε **Save as PDF**. Η φόρμα δεν εμφανίζεται στην εκτύπωση.

## Παραμετροποίηση

Όλες οι ρυθμίσεις βρίσκονται στο `<script>` στο κάτω μέρος του αρχείου.

| Τι | Πού | Σημειώσεις |
|---|---|---|
| Φωτογραφία κεφαλίδας | `PANORAMIC_URL` | Direct link εικόνας |
| Φωτογραφία placeholder | `PLACEHOLDER_IMG` | Εμφανίζεται όταν μια φωτογραφία λείπει ή δεν φορτώνει |
| Τύποι δωματίων | `roomDatabase` | Κάθε εγγραφή έχει `isClub`, `folder`, `photos` (4 links) και `description` |
| Μέγιστος αριθμός γραμμών δωματίων | `MAX_ROOMS` | Προεπιλογή 5. Άλλαξε και το κείμενο στο `renderRoomsAdmin()` και στη σημείωση της φόρμας. |
| Κωδικός | `PASSWORD_HASH` | SHA-256 hash του κωδικού (δες παρακάτω) |

### Προσθήκη νέου τύπου δωματίου
Πρόσθεσε μια νέα εγγραφή στο `roomDatabase`:

```js
"Όνομα Δωματίου": {
    isClub: false,              // true για παροχές Miraggio Club
    folder: "…",                // πληροφοριακό μόνο
    photos: ["url1", "url2", "url3", "url4"],
    description: "Περιγραφή που εμφανίζεται στην επιστολή."
},
```

Το νέο δωμάτιο εμφανίζεται αυτόματα στη λίστα της φόρμας. Ένα δωμάτιο παίρνει τις παροχές Club όταν έχει `isClub: true` ή όταν το όνομά του περιέχει "Club" ή "Suite".

### Direct links για φωτογραφίες
Τα κανονικά links κοινοποίησης δεν δουλεύουν ως εικόνες και πρέπει πρώτα να μετατραπούν:

- **Google Drive**: όρισε το αρχείο ως "Anyone with the link". Από το `https://drive.google.com/file/d/FILE_ID/view?usp=sharing` πάρε το `FILE_ID` και γράψε
  `https://drive.google.com/thumbnail?id=FILE_ID&sz=w1000`
- **Dropbox**: στο `https://www.dropbox.com/s/abc123/photo.jpg?dl=0` άλλαξε το `www.dropbox.com` σε `dl.dropboxusercontent.com` και σβήσε το `?dl=0`.

### Αλλαγή κωδικού
Βγάλε το SHA-256 του νέου κωδικού και βάλ' το στο `PASSWORD_HASH`:

```bash
echo -n 'ΝέοςΚωδικός' | sha256sum
```

## Σημειώσεις και περιορισμοί

- **Ο κωδικός προστατεύει μόνο από περιστασιακούς επισκέπτες, δεν είναι πραγματική ασφάλεια.** Η σελίδα είναι στατική, οπότε όλο το περιεχόμενό της φτάνει στον browser και κάποιος που ξέρει μπορεί να παρακάμψει τον έλεγχο. Για πραγματικό έλεγχο πρόσβασης, το hosting πρέπει να είναι ιδιωτικό.
- Ο έλεγχος κωδικού χρησιμοποιεί το `crypto.subtle`, που λειτουργεί μόνο σε ασφαλές περιβάλλον: HTTPS, `localhost` ή τοπικό αρχείο. Σε απλό `http://` προς άλλη διεύθυνση δεν θα ξεκλειδώσει.
- Το προτεινόμενο όνομα αρχείου PDF λειτουργεί καλύτερα σε Chrome και Edge. Για να βγουν στο PDF τα χρώματα φόντου, ενεργοποίησε το "Background graphics" αν ο browser δεν το κάνει αυτόματα.
- Τα στοιχεία της φόρμας δεν αποθηκεύονται. Με ανανέωση της σελίδας χάνονται.
